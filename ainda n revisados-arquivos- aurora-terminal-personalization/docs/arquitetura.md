# Arquitetura

O projeto separa diagnóstico, dependências, configuração e restauração.

- O Aurora/DX e o Aurora CLI são preparados manualmente.
- Homebrew fornece ferramentas ausentes no diretório do usuário.
- Os modelos ficam no repositório.
- A configuração ativa fica no diretório pessoal.
- Backup precede qualquer futura substituição.
