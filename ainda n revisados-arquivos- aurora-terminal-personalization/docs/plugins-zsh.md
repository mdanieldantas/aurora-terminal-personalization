# Plugins Zsh

Plugins planejados para instalação no diretório do usuário:

- `zsh-autosuggestions` — sugestões baseadas no histórico.
- `fast-syntax-highlighting` — destaque da linha de comando.
- `zsh-history-substring-search` — busca por trecho no histórico.
- `zsh-vi-mode` — modo Vim opcional.

Nenhum plugin é instalado nesta fase.
